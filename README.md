# That Sky Mod 简体中文社区翻译

这是 That Sky Mod（TSM）PC 版的非官方简体中文社区翻译，当前适配 **TSM v0.50.0**。

- 安装文件：[zh-cn.json](TSM%20Resources/i18n/zh-cn.json)
- 完整修改记录：[CHANGELOG.md](CHANGELOG.md)
- 贡献与致谢：[CREDITS.md](CREDITS.md)

本项目只提供语言文件和中文说明，不包含 TSM 程序本体。TSM 的下载、更新和 Discord 授权仍以作者 Trinity 的官方频道及 App 为准。

## 安装

1. 在 TSM App 中点击 `Open mod install folder`，打开 Mod 安装文件夹。
2. 下载本项目中的 `zh-cn.json`。
3. 将语言文件放到：

   ```text
   Mod安装文件夹\TSM Resources\i18n\zh-cn.json
   ```

4. 如果已有同名文件，请直接覆盖。
5. 启动 TSM；如果已经打开，请重新扫描语言文件或重启 TSM。
6. 在语言选项中选择 `Chinese (Simplified)`。

更详细的图文步骤请参阅[安装与基础使用说明](docs/installation.md)。项目只提供这一份语言文件，不再提供额外的安装 ZIP。

## 为什么语言名称使用英文

语言名称特意写成 `Chinese (Simplified)`，而不是中文。这能保证在中文字体尚未加载时，语言选项仍然可以辨认，避免显示为 `??`。这种处理不依赖 Trinity 修改界面或更换字体。

语言代码采用 `zh-CN`，用于明确标识简体中文，并与未来可能出现的繁体语言包区分。如果某个依赖语言代码的功能出现异常，请在反馈中说明具体功能；发布前会重点测试语言切换、重启后记忆和聊天自动翻译。

## 为什么没有附带中文字体

本翻译使用 TSM 自带的 `Default.ttf`。实际测试中，它能够正确显示中文界面和中文好友名称，因此不再捆绑额外字体文件。这样下载更小、安装更简单，也避免第三方字体授权和清晰度问题。

## 翻译原则

### 1. 修正明显错误，并以实际功能为准

| 英文 | 原翻译 | 当前翻译 |
| --- | --- | --- |
| `Fast Meditate` | 快速传送 | 快速冥想(含回家) |
| `Steps` | 步数 | 步骤 |
| `Carry` | 背负 | 肩背 |
| `Aurora` | 极光 | AURORA |
| `The Citadel` | 城堡 | 霞光城 |

`Fast Meditate` 现在会跳过所有冥想点的等待，包括回家，因此没有继续沿用只强调传送的旧译。

### 2. 结合国服、国际服和任务文本统一地名

| 英文 | 当前翻译 |
| --- | --- |
| `Aviary Village` | 云巢 |
| `Village of Dreams` | 圆梦村 |
| `Butterfly Fields` | 蝴蝶平原 |
| `Prairie Village` | 云中仙乡（三塔图） |
| `Bird Nest` | 云顶浮石（右图） |
| `The Citadel` | 霞光城 |

地名不会一律直译，而是结合 Steam 官方简体中文、国服常用称呼、国际服语境、每日任务文本和玩家实际交流习惯进行取舍。必要时加入“三塔图”“右图”等注解，帮助玩家快速辨认位置。

### 3. 不拘泥于直译，以方便使用为最终目的

| 英文 | 当前翻译 | 处理理由 |
| --- | --- | --- |
| `Automation` | 跑图辅助 | 比“自动化”更容易理解该页功能 |
| `Wax` | 自动跑图(慎) | 该独立入口实际对应全自动收集烛火，并提示风险 |
| `Overlay` | 悬浮显示 | 比“叠加层”更符合中文界面习惯 |
| `Discord Rich Presence` | Discord 游戏活动状态 | 避免生硬直译，同时与普通状态区分 |
| `in {}` | 还有 {} | 符合近期事件倒计时的显示语境 |

`自动跑图(慎)` 中的“慎”是翻译者提供的风险提示，不代表任何安全保证。

## 反馈与参与

发现翻译错误时，建议提交 Issue，并尽量附上：

- 当前使用的 TSM 版本；
- 英文原文或 JSON 键名；
- 当前中文；
- 出现位置和截图；
- 建议译法及理由。

同一个英文键可能在 TSM 的多个位置重复使用，例如 `Home` 和 `Actions`。如果不同位置需要不同中文，但程序只提供一个共用键，请同时说明两个使用场景，我们会根据整体可读性取舍。

如果你参与过早期翻译，欢迎联系我们补充署名。

## 更新方式

本项目不另外维护中文翻译版本号。翻译会持续修正和补充，更新情况可以直接查看 GitHub 的文件更新时间、提交历史和 `CHANGELOG.md`。

README 顶部只标明当前适配到哪个 TSM 版本。TSM 大更新后，我们会对比新版英文文件并更新兼容信息。安装文件始终叫 `zh-cn.json`，更新时直接覆盖旧文件即可。
