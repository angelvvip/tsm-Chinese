# 安装与基础使用

## 准备工作

本项目不提供 TSM 本体，也不能替代 TSM 的 Discord 成员检测或授权。请先按照 Trinity 官方 Discord 频道的说明安装并正常启动 TSM App。

## 安装语言文件

1. 在 TSM App 中找到并点击 `Open mod install folder`。这个按钮会直接打开当前使用的 Mod 安装文件夹，不需要手动查找路径。
2. 完全关闭 TSM，避免正在使用的语言文件没有及时刷新。
3. 下载本项目中的 `zh-cn.json`。
4. 在刚才打开的 Mod 安装文件夹中，依次进入 `TSM Resources` 和 `i18n`。
5. 把 `zh-cn.json` 放入其中。如果已有同名文件，请先自行备份，然后覆盖。
6. 重新启动 TSM，在语言选项中选择 `Chinese (Simplified)`。

最终路径应类似：

```text
Mod安装文件夹\TSM Resources\i18n\zh-cn.json
```

不要更改安装文件名，也不要同时保留多个中文 JSON，否则语言菜单可能出现重复选项。

## 更新翻译

1. 在 README 顶部确认当前翻译适配到哪个 TSM 版本。
2. 根据 GitHub 的文件更新时间、提交历史或 `CHANGELOG.md` 判断是否有更新。
3. 下载新的 `zh-cn.json`。
4. 覆盖 `TSM Resources\i18n` 中的同名文件。
5. 重启或重新扫描语言文件。

如果你的 TSM 版本比 README 标明的适配版本更新，旧翻译通常仍可加载，但新功能可能显示英文或缺少说明。此时请等待适配更新或提交反馈。

## 常见问题

### 语言列表显示问号

本翻译的菜单名称只包含英文字符，正常情况下应显示为 `Chinese (Simplified)`。如果连英文也变成问号，问题可能不是中文字体，而是文件编码、JSON 损坏或语言文件未完整下载。

### 选中后部分内容仍是英文

可能原因包括：

- TSM 更新后增加了新的英文键；
- 某些内容由服务器或游戏运行时提供；
- 同一个界面包含 Mod 文本和游戏官方文本；
- 当前功能没有使用语言文件中的对应键。

反馈时请附上截图、TSM 版本以及下载语言文件的大致日期。

### 安装后没有出现中文选项

请确认：

- 文件名确实是 `zh-cn.json`，而不是 `zh-cn.json.txt`；
- 文件位于 `TSM Resources\i18n`，没有多套一层解压目录；
- JSON 文件下载完整；
- 已重新启动或重新扫描语言文件。
