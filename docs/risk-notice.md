# 功能风险提示

语言文件只改变界面显示，不会改变 TSM 功能本身，也不能让任何功能变得更安全。

TSM 中部分功能可能会：

- 自动移动、自动跑图或自动收集烛火；
- 向游戏服务器发送数据；
- 修改解锁状态或账号数据；
- 向当前场景中的其他玩家发送或显示效果；
- 执行原本需要玩家手动完成的操作。

这些功能的风险可能高于单纯的界面、画面或本地辅助功能。翻译中的“慎”“向服务器发送”等文字，是为了让中文玩家在启用前更容易理解实际行为，不代表已经验证安全，也不构成不会封号的保证。

建议：

1. 不理解功能说明时先不要开启。
2. 自动化功能不要长时间无人看管运行。
3. 涉及账号解锁、服务器数据或其他玩家的功能尤其谨慎。
4. TSM 更新后先查看官方更新说明，再确认旧设置是否仍适用。
5. 重要账号不要依赖“其他人使用过没有问题”作为安全依据。
